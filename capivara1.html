Capivara 1

Fichas para as suas fontes primárias.

A primeira versão do programa: entradas com metadados editáveis, transcrição, notas, etiquetas e arquivos vinculados, buscas e filtros, sozinho ou em equipe numa pasta compartilhada. Gratuito, em português, e tudo fica no seu computador ou na pasta de nuvem da sua equipe.

Baixar para Windows

Capivara 1 · 215 MB · Windows 10 e 11

Procurando a versão mais nova? O Capivara 2 tem aparência e recursos novos e abre os projetos feitos no Capivara 1 (o projeto antigo não é alterado: o Capivara 2 cria uma cópia). Esta página é para quem continua trabalhando com o Capivara 1.

Instalação

Instalar em quatro passos

Não é preciso instalar mais nada antes (nem Python, nem outros programas). O Windows vai mostrar um ou dois avisos no caminho: eles são esperados, e abaixo explicamos o que clicar.

1

Baixe o instalador

Clique em Baixar para Windows, no alto desta página. O arquivo se chama Capivara1_Instalador.exe e vai para a pasta Downloads.

Se o navegador avisar que o arquivo “não é baixado com frequência” ou “pode ser perigoso”:

No Edge: passe o mouse sobre o aviso, clique nos três pontinhos Manter, depois Mostrar mais e Manter mesmo assim.
No Chrome: clique em Manter (ou Baixar arquivo suspeito).

2

Abra o instalador e passe pelo aviso do Windows

Dê dois cliques no arquivo baixado. O Windows deve mostrar uma janela azul dizendo “O Windows protegeu o computador”, sem nenhum botão para continuar. Não feche a janela:

O Windows protegeu o computador O SmartScreen impediu a inicialização de um aplicativo não reconhecido…
Mais informações
Aplicativo: Capivara1_Instalador.exe
Editor: Editor desconhecido
Executar assim mesmoNão executar

Ilustração simplificada · os contornos marcam onde clicar

Clique em Mais informações (o texto sublinhado). Aparece então o botão Executar assim mesmo: clique nele.

3

Siga o assistente de instalação

Clique em Avançar até o fim e, no final, em Concluir. Se o Windows perguntar se você permite que o instalador faça alterações no computador, clique em Sim.

4

Abra o Capivara 1

Procure Capivara no menu Iniciar (ou use o atalho da Área de Trabalho, se o instalador criou um). Na primeira vez, o programa pede o seu nome: use sempre o mesmo nome, porque é por ele que a equipe sabe quem fez cada alteração e quem está editando cada entrada. Depois, escolha Novo Projeto para começar ou Carregar projeto para abrir um que já exista. O botão Manual de uso, na primeira tela, abre o manual do programa.

Sobre o aviso

Por que o Windows mostra esse aviso?

O Windows avisa sobre qualquer programa que não tenha uma assinatura digital, um certificado comprado de uma empresa e renovado todo ano. O Capivara é um projeto acadêmico gratuito e não tem esse certificado. O aviso quer dizer apenas “não sei quem fez este programa”, e não que o programa seja perigoso.

O Capivara não envia suas fontes para a internet: tudo fica no seu computador ou na pasta de nuvem que você escolher.

Computador da universidade ou do trabalho sem o botão “Executar assim mesmo”? Nesses computadores, quem decide o que pode ser instalado é o setor de informática. Envie a eles o link desta página e peça a instalação do Capivara 1.

Para quem quer conferir se o arquivo é o original

Esta é a “impressão digital” (SHA-256) do instalador do Capivara 1:

2EAC9FD6D9D3AB8719D3807E37922798F3A88F72D6701DAB74BCEF026549CB19

Para conferir, abra o PowerShell na pasta Downloads e digite Get-FileHash Capivara1_Instalador.exe. Os dois códigos devem ser iguais.

Bom saber

Antes de começar

Trabalhar em equipe

A equipe compartilha a pasta do projeto pelo OneDrive, Google Drive ou Dropbox. Cada pessoa usa o seu nome, e o programa avisa quando uma entrada está sendo editada por outra pessoa. Todos devem usar a mesma versão do Capivara.

Quer migrar para o Capivara 2?

Instale o Capivara 2 e use Arquivo › Migrar projeto do Capivara 1…. O projeto antigo não é alterado.

Seus projetos

Ficam nas pastas que você escolheu, não dentro do programa. Instalar de novo ou atualizar o Capivara não apaga os seus projetos.

Requisitos

O que é preciso

  • Computador com Windows 10 ou 11.
  • Cerca de 215 MB para baixar o instalador, além do espaço do programa instalado e dos seus projetos.
  • Para trabalhar em equipe: OneDrive, Google Drive para computador ou Dropbox instalado.
  • Não é preciso internet para usar o programa, só para baixar o instalador.

Ajuda

Dúvidas e problemas

Consulte primeiro o Manual de uso, que está dentro do programa (botão na primeira tela). Se algo der errado, envie uma descrição do problema para policroniasdopresente@gmail.com. Se o programa mostrar uma mensagem de erro, copie o texto dela na mensagem; os erros também ficam registrados em logs/erros_capivara.txt, dentro da pasta do projeto.
